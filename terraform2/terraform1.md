Terraform – Session 1

🔹 Infrastructure as Code (IaC) – Using configuration files to create and manage infrastructure.

🔹 Providers, Resources & Data Sources – Understanding how providers connect to platforms, resources create infrastructure, and data sources retrieve existing information.

🔹 Terraform Workflow – Practising the basic commands:

terraform init – Initialise the working directory.

terraform plan – Preview infrastructure changes.

terraform apply – Apply infrastructure changes.

terraform destroy – Remove managed infrastructure.

🔹 Local Provider – Practising Terraform using local resources before moving to cloud infrastructure.

🔹 AWS Infrastructure – Using Terraform to create a custom VPC and configure security groups.
